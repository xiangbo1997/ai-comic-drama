# 漫剧生成与体验优化：第二轮

> 阶段历史记录。本文所列持久向导、数据库并发、分镜原子事务等后续工程项已继续实现，当前保证与最终验收见 [最终交付](optimization-final-2026-11.md)。真实样片、投放与物理设备边界仍以最终报告如实区分。

日期：2026-11-13。本轮接续竞品研究后的首轮优化，三个子 agent 分别负责手机编辑、制片人重试和审片版本校验；主 agent 修复生成到落库的断点并集成验收。

## 已实现

| 方向             | 原问题                                                                       | 当前行为                                                                                                                                         |
| ---------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 生成结果真正生效 | 增强、修订后的分镜只存在于工作流 artifact，编辑器与导出仍读原始分镜          | 审阅定稿先同步数据库，再交给下游；按原镜序更新，保留现有分镜 ID 与媒体，不重新建镜                                                               |
| 角色与环境连续性 | 生产解析器与共享 schema 各自维护，地点、换装、站位与结尾钩子等字段被静默剥除 | 生产解析与分镜补全复用共享 schema，保存节拍、高潮和轴线；源剧本已有的地点、换装、站位优先，模型空值、非法值或局部改写不能抹掉                    |
| 镜序与口播       | 补全结果可能缺镜、重复、跳号或乱序，修订台词后镜长未重算                     | 每批严格核验镜号集合，异常重试后回落原剧本；恢复原顺序并规范媒体回写序号，重算完整对白/旁白所需镜长，生产边界统一支持 1–60 秒输入                |
| 手机基本创作     | 手机隐藏输入与逐镜编辑，长标题挤出工具                                       | 创作／分镜／编辑切换，面板持续挂载保留草稿，选镜和审片定位进入编辑，窄屏顶栏适配，桌面保留三栏与折叠偏好                                         |
| 制片人重试       | 相同脚本重试启动重复任务，角色查重失败仍创建，最后保存失败却显示完成         | 显式制片人请求按完整输入复用服务端任务，事务锁保护查建；查重失败停止；完成脚本必须仍存在；同一向导实例收尾失败重试保留已成功应用的分镜与已有配置 |
| 审片可信度       | 改台词、倍速或换图后仍展示旧高分为当前结论                                   | 文本和视觉独立记录输入指纹；变动显示“已过期”，历史无证据显示“无法核验”，不把历史评分和建议当当前结论，也不自动调用付费评审                       |

这些变化提高生成链路的一致性与可操作性，尚无真实样片或平台留存数据证明“爆款率”变化。

## 已确认的后续取舍

- 完整五步刷新恢复需要服务端 checkpoint；本轮只保证脚本任务可复用、同一打开实例的收尾可重试。项目创建响应丢失、跨标签页并发建角色、分镜 POST 成功但响应丢失尚未全部解决。
- 事务锁的路由回归使用 mock，未对真实 PostgreSQL 做多连接并发或进程崩溃注入。项目配置 GET 后合并仍存在跨客户端并发写入窗口。
- 分镜同步使用既有逐镜更新，并非全项目原子事务；失败会阻止下游发布，不能保证此前已更新的行全部回滚。
- 视觉指纹基于素材 URL，不能发现同 URL 文件内容被外部替换。保留已有媒体不会使其自动重新生成；用户修改剧情后仍需按需生成并复查素材。
- 手机已验证基本创作和逐镜编辑；触屏拖拽、系统软键盘、长片多轨时间轴及全部装饰弹窗没有完整移动验收。
- 未运行需数据库和账号的完整受保护页面 E2E，未生成付费图像、视频或语音，未改数据库结构或部署。
