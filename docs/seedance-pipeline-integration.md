# Seedance 调研中有用能力的主流程整合

2026-11-19，基于开发分支 `feat/ai-abstract-short-video`（起点 `d3aa600`）独立整合。研究分支的“制作包与场记”四分区工作台、独立 API、ZIP 导出及手填计划不合入本次变更。

## 用户能感知的变化

### 原有自动制作计划提前展示参考素材缺口

打开当前作品的 AI 助手 → 自动制作 → 查看执行计划。对需要补图的分镜，计划会检查其角色关联、定妆/参考图，以及所选图片模型是否支持参考图。

- 角色没有定妆图和参考图时提示先到现有角色页准备；同一角色只提醒一次。
- 角色关联失效时提示对应镜头重新选择角色。
- 所选图片模型不支持参考图时明确提示，避免把已有角色/地点图误当成实际约束。
- 已有图且不需要补图时不强加这类警告；已有参考图时不重复提醒缺图。

这类信息是现有计划的警告，不自动改模型、不额外生成角色图、不增加隐藏步骤或费用。地点参考仍复用既有补图步骤和预算，模型选择/执行继续由用户确认。

### 原有 AI 场记增加道具与空间检查

原编辑器“AI 场记”与助手自动制作中的视觉检查，继续对比实际相邻图片；增加两个检查维度：

- **道具状态**：可辨识的同一道具是否无故换手、变形或改变完好状态。
- **空间站位**：同地点场景的轴线、视线、人物与陈设关系是否出现没有剧情依据的异常。

复用已有 `description`、`actionBeat` 与 `screenSide`，不要求用户额外填写一套账本。检查会考虑剧情交接/损坏/走位；遮挡、出画、正常正反打或看不清不能直接判错。跨地点不比较空间站位，文字左右坐标差异也不能代替视觉判断。

结果仍进入原报告与逐镜卡片，并携带 `fixNote`。手动“按建议重生成”沿用现有参考图迭代；自动制作只将严重问题按镜头合并到已有预算内的修复队列，中等/轻微问题保留报告。没有新增自动重试或付费调用路径。

动作/站位变化会令旧报告失效；检查方法也有版本标识，因此此前只检查五个维度的报告需要重查。视觉调用失败保持“未完成/跳过”，不伪报通过。真实效果仍取决于所选视觉模型，本次使用模拟供应商验证行为，没有额外付费效果测试。

### 视频生成正确处理明确的 OS/VO 声源

旧编辑器单镜、多模型视频、Workflow 和助手自动视频生成共享同一声源判定；服务端导演增强也遵守，并将对白来源纳入缓存版本。

| 已有对白文本 | 行为 |
|---|---|
| `阿宁：别开门` | 可见景别按原规则允许自然口型，声音继续后期配音 |
| `阿宁（OS）：别开门`、`【内心独白】别开门` | 不要求画面人物张嘴 |
| `阿宁（画外音）：别开门`、`VO: 别开门` | 不要求画面人物张嘴 |
| 无对白，只有旁白 | 不要求画面人物张嘴 |
| 同镜多行同时有当面对白与 OS/VO | 保留当面对白所需口型 |

只识别行首的明确标签；台词正文出现“心想”“画外音”等字眼不作推断。未标记的对白继续视为当面对白。旧的 `hasDialogue` 调用仍兼容。文本内容、TTS、字幕和原声混音设置不在本轮改写。

独立短视频模块的原始 `videoPrompt` 和既有 worker/预算合同保持现有行为；没有把该模块强制改走漫剧导演增强。没有增加 Seedance 原生多模态、延长或外部平台发布能力。

## 工程边界与回滚

不新增页面、独立业务模型、schema 迁移或依赖。只增强现有计划、视频提示词、视觉场记、结果指纹和原 UI 说明；开发分支已经完成的短视频功能保留。

源码与测试在整合 worktree 验证，验证记录见 `.codex/verification.md`。合并仅更新开发分支代码，不等于部署上线。若需回退，使用本次整合提交的 revert；无需删除业务数据或资产。
