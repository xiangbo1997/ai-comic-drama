# 短视频简易创作与编辑器共用

作品页默认先显示「简单创作」，参考简报、标题管理和站内模型改编可按需展开。

## 已有简报，想交给其他 AI

1. 点击「复制改编提示词」或「下载提示词 TXT」，粘贴到常用文本 AI。
2. 把 AI 回复中的完整脚本 JSON 或包含单个 JSON 代码块的回复，粘贴到「粘贴 AI 返回的脚本」。确认识别出的标题、镜头数与时长，点击「应用到脚本表单」。
3. 检查并「保存为新版本」。已有草稿会在替换前询问，已保存版本保留。

只有简报或不完整草稿时，导出标为「待改编」。普通文字、Markdown 表格不是结构化分镜，系统不会假装已经解析为完整脚本。需有开场、设定、1–5 镜、每镜首帧与视频动作等字段才能通过脚本校验。JSON 围栏也适用于高级编辑和站内模型返回结果，不会触发自动修复或追加模型请求。

## 已有脚本，想在其他平台制作

「复制完整创作提示词」/「下载提示词 TXT」导出当前编辑内容，包含未保存的修改：画幅、总时长、镜头时间段、角色和外观、首帧生图提示词、视频动作、台词、旁白、字幕、连续性与剪辑要求、封面制作指令、发布文案、完整回导 JSON，以及原参考简报。简报不会按故事设定的 1000 字上限截断。

逐镜把首帧与动作交给目标生图/视频平台，再剪辑、配音和添加字幕。平台对时长、参考图和声音的支持不同，需要按对应平台操作。复制和下载在浏览器本地完成，不需要成片、发布账号或站内模型，也不触发模型请求。复制被浏览器拒绝时，可下载或展开提示词手动复制。

可直接使用的原创示例：[仙门严苛训练完整提示词](examples/仙门严苛训练-完整创作提示词.txt)，以及[可导入的两镜脚本](examples/xianmen-training.script.json)。示例由用户提供的扫帚反差笑点补写，20 秒竖屏、两位成年角色、两个镜头；来源采集时间不作为原作品发布时间。

## 用当前项目的编辑器制作

保存完整脚本后，点击「将已保存脚本带入编辑器」。首次创建使用当前选择的已保存版本，把角色建档、出场引用、分镜画面、首帧、视频动作、台词/旁白、秒数、独立字幕带入 `/editor/{projectId}`。完整原始资料与脚本保存在编辑器原文中，原短视频脚本版本保留。

在同一编辑器使用已有角色库、定妆参考图、图片/视频生成、配音、时间轴、字幕、配乐、预览和成片导出。进入编辑器本身不调用模型；主动生成时仍使用既有模型、预算和确认流程。导出 MP4 后回到短视频作品页上传，继续审核与人工发布。

已有编辑器项目时显示「打开已有编辑器项目」，重开保留其中的修改；不会再次导入、追加或覆盖分镜。短视频脚本与编辑器目前为首次拷贝，不自动双向同步；短视频页导出的提示词来自该页当前脚本。后续编辑器修改需在编辑器中保存，成片需上传回短视频。站内生成计划沿用原有独立版本/素材流程。

## 实现与接口

- Markdown 展示复用 `AssistantMarkdown`，支持 GFM 加粗、表格、来源链接；禁用原始 HTML、危险链接与外部图片自动加载。
- `POST /api/short-videos/videos/{id}/editor`：`requestId`、`expectedVideoVersion`、`scriptVersionId`。沿用短视频开关、登录、同源校验、限流和归属校验。
- 复用现有 `SvVideo.projectId`，无需数据库迁移。现有请求收据、用户事务锁与原子提交保证并发点击只创建一个项目；归档/过期版本/其他用户脚本拒绝创建。关联项目仍需属于当前用户。
- 不完整表单不再把截断的简报自动塞进「故事设定」。手写时只填本片剧情，原简报仍在作品与提示词中。
