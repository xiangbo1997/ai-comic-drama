# 角色生成入口

角色参考图、三视图、表情集分别确认生成，支持同一角色的不同类型任务同时运行。

- 角色图上的 AI/上传按钮打开参考图弹窗；可选择 1、2、4 张候选，并明确显示单价与本次总价。
- 角色卡上的“三视图”打开专项弹窗，生成正面、侧面、背面；“表情集”生成六种表情。专项不显示普通参考图的候选张数或图片来源。
- 专项弹窗显示实际使用的定妆照，未指定定妆照时使用首张参考图。没有图片时仍可根据角色信息生成三视图；表情集须先有参考图。
- 每个弹窗只有一个生成确认按钮，费用对应当前任务。任务提交后关闭弹窗，在角色卡对应入口显示生成状态，其他类型仍可操作。
- 同一角色的同类任务进行中禁用重复生成，成功或失败后恢复入口。不同角色之间的任务继续独立。

本次仅调整前端入口和状态管理，沿用现有 API 与计费规则。
