# 助手自主执行上下文（2026-11-14）

用户明确要求实现此前说明的自动流程：地点参考→补齐图片→连贯性检查→有限修复/复查→适当衔接→视频；展示计划和预算，一次确认后可后台执行、停止、失败续跑及保留旧版本。

sequential-thinking不在当前工具列表，三个codex项目协议技能仍沿用已确认缺失状态；人工阶段推理与回退如下。已有AI助手已部署，所有未提交更改和原有用户文件保留。沿用已加载的TDD、安全、前后端、API及验证技能；继续此前用户明确授权的三个agent协作。

人工推理：现有producer checkpoint使用GenerationTask终态容器持久状态与租约，适合复用其设计；旧WorkflowEngine会重建剧情/分镜且取消与重启恢复不足，不直接套用。真实执行必须在服务器完成，不依赖浏览器串行fetch或聊天模型自称成功。只操作用户当前项目，系列总览先选集。优先复用已有计费、生成、地点锚图、视觉检查和视频能力；预算须在上游调用前硬限制，未知调用结果必须阻止自动重复。

计划：1.审查现有能力并明确API/执行适配契约；2.持久计划与执行器、真实工具适配、助手执行UI并行实现；3.授权/预算/幂等/停止恢复/旧版本保护单测、真实隔离PG及浏览器验证；4.全应用类型/lint/测试/隔离生产构建及文档。

并行：backend负责状态/预算/租约/API；context-model负责真实工具服务适配；product-ui负责助手执行入口、计划/进度/停止恢复和浏览器测试；root负责契约、集成与独立审查。分析阶段先不改生产文件，契约统一后分配文件所有权。

回退：仅按本次新增与修改文件回退，不reset既有工作区；不触发真实付费生成作验证。测试只用新建临时数据库、假上游和模拟作品。生产部署授权沿用会话，但先完成可审查实现与验收，再按实际变更准备备份/迁移/上线流程；不让开发过程污染运行中的线上构建。
